# X Close

Android 無障礙服務：在您手動啟用後，自動點擊已確認可操作的廣告「X」關閉按鈕。

## 目前版本

- **0.2.2**（versionCode 38）
- 檔案：`x-close-0.2.2-debug.apk`（debug 簽章的測試 APK）
- SHA256 見 `SHA256SUMS.txt`

## 安裝與使用

1. 安裝 APK（Android 11 以上）。
2. 開啟 App，閱讀並同意無障礙揭露。
3. 到系統無障礙設定中啟用 X Close，再回到 App 開始。
4. 暫停、繼續、停止可從通知操作。

## 限制

- 只點擊畫面上確認可操作的 X；不保證廣告已結束或獎勵已發放。
- 不確定時不點擊；不擷取、不保存、不上傳畫面。
- 目前版本的 LINE 廣告 SVG 關閉鈕修正已安裝，效果未驗證，其他廣告形態未全部測試。
- 完整原始碼未在本倉庫公開。
