# X Close

Android 自動點選關閉 X 的測試工具。手動開始後，辨識前景 App 中符合條件的 X；包含廣告與一般彈窗。提供例外清單與通知中的暫停、繼續、停止。

## 下載與安裝

到 [Releases](https://github.com/YihongTools/x-close/releases/tag/v0.2.0-alpha.14) 下載 APK。此倉庫用於 APK 發布與使用說明，目前不包含完整原始碼。

目前版本 **0.2.0-alpha.14（versionCode 30）**，Android 11 以上。這是使用 Android debug 簽章的預發布測試 APK，尚非正式穩定版，也未經 Google Play 審核。下載後依手機提示安裝，閱讀 App 用途說明並同意，在系統無障礙設定啟用 X Close、允許通知，再按「開始」。重新啟動不會自動開始。

## 範圍與限制

- 明確 X／Close／關閉文字節點，或經兩次圖像確認的可操作 X，才代為點擊；不使用固定座標手勢。
- 無法通用判定廣告是否播放完畢或獎勵已發放，可能誤關視窗或影響獎勵；不保證所有廣告均可關閉。
- 僅 LINE 散步趣指定 AppLovin 頁面有額外備援：連續三分鐘無合格 X 候選時返回一次；或在無 X 候選且存在唯一、限定位置的精確 Google Play 控制項時點一次，隨即確認商店前景後返回一次，再辨識 X。控制項缺失時不盲點，不操作安裝或付款。
- 特殊商店流程已通過合成測試。實機已分別觀察自動開商店、手動返回後自動關 X；最終版在真實廣告完成整段全自動往返仍未驗證。
- 這份測試 APK 啟用本地測試規則；Gradle release 變體的自動操作仍停用，兩者不可混為一談。

## 隱私

畫面只在本機記憶體暫時處理，不保存、不上傳。App 沒有網路權限；例外清單與同意狀態儲存在手機，辨識計數僅暫存。測試 APK 會在裝置系統日誌輸出視窗狀態與計數，不公開提交裝置日誌。停止或暫停可從通知操作，無障礙設定入口可撤回同意。

建置與 lint、實際支持按鈕目的網址測試通過。廣告流程先前完成 16 項特殊商店流程、20 項 X 辨識、12 項無 X 返回合成驗證；這些不代表所有真實廣告均成功。alpha.14 保留原樣單行「支持開發 / 問題回報」，兩段文字分別開啟支持網站與郵件草稿；已通過文字範圍觸控、郵件預填與缺少郵件App時複製信箱的測試，以及一般／小螢幕大字單行檢查。本次未改廣告流程，未重跑其回歸。
